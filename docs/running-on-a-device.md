## שגרה יומית

```
npx expo start
```

ואז לפתוח את **showmi** בטלפון. זהו.

שינית קוד ולא רואה את זה? סגור את האפליקציה לגמרי (החלק מלמטה והעף אותה)
ופתח שוב.

---

## בנייה מלאה

```
npx expo run:ios --device 00008130-001C10261A0A001C
```

המספר הוא ה-UDID של האייפון שלך. בלעדיו הפקודה תעצור ותבקש לבחור מכשיר.
לראות אילו מכשירים מחוברים:

```
xcrun devicectl list devices
```

### לפני שמריצים

- הטלפון מחובר **בכבל נתונים** (כבל טעינה בלבד לא יעבוד, והטלפון ייטען
  כרגיל — זו תקלה מטעה)
- הטלפון **פתוח, ונשאר פתוח** לאורך כל הבנייה. נעילה באמצע מפילה את
  ההתקנה בשלב האחרון
- אישרת פעם אחת "לתת אמון במחשב הזה"

## תקלות שכבר נתקלנו בהן

### `Developer Mode disabled`

בטלפון: **הגדרות › פרטיות ואבטחה › מצב מפתח** › להדליק. הטלפון יבקש להפעיל
מחדש ואז לאשר שוב.

הסעיף הזה מופיע רק אחרי שנעשה ניסיון להתקין אפליקציית פיתוח. אם חיפשת אותו
ולא מצאת — תריץ את פקודת הבנייה פעם אחת, היא תיכשל, והסעיף יופיע.

### `errSecInternalComponent`

הבנייה הצליחה ונפלה בחתימה. macOS צריכה להציג דיאלוג שמבקש רשות להשתמש
במפתח החתימה, ודיאלוג לא יכול להופיע בתהליך רקע.

**תריץ את הפקודה בטרמינל שלך** ולחץ **"אפשר תמיד"** — לא "אפשר", אחרת זה
יחזור בכל בנייה.

### `No space left on device`

הדיסק מלא. בנייה ל-iOS צורכת כמה ג'יגה. מה שבטוח לפנות:

```
rm -rf ~/Library/Developer/Xcode/DerivedData/*
rm -rf ~/Library/Caches/CocoaPods
npm cache clean --force
```

כולם נבנים מחדש לבד. אפשר גם למחוק runtime של סימולטור שאינך משתמש בו
(`xcrun simctl runtime list` ואז `delete`) — זה בדרך כלל הפריט הגדול ביותר.

### האפליקציה נפתחת ונסגרת מיד

אם זה קורה אחרי שינוי ילידי, כדאי לראות את דוח הקריסה עצמו ולא לנחש:

```
xcrun devicectl device info files --device <UDID> \
  --domain-type systemCrashLogs --search showmi
```

ואז להעתיק את הקובץ האחרון עם `xcrun devicectl device copy from`. ה-backtrace
אומר בדיוק מה קרה — ככה נמצאה הקריסה של iOS 26.

### "לפתוח ב-showmi?" בכל לחיצה על קישור התחברות

זו התנהגות רגילה של iOS לכל סכימת URL מותאמת אישית, לא באג. היא נעלמת רק עם
Universal Links, שדורשים דומיין אמיתי.

## לאחר שינוי ב-`app.json`

```
npx expo prebuild -p ios
npx expo run:ios --device 00008130-001C10261A0A001C
```

**שים לב:** `prebuild` מוחק את הגדרת החתימה שהוגדרה ב-Xcode. `expo run:ios`
מחיל אותה מחדש לבד, אז אין מה לעשות — רק אל תחפש בהגדרות משהו שנמחק
אוטומטית.

אם `prebuild` נכשל עם `ENOTEMPTY`, סגור את Xcode ונסה שוב.
